# Live checks and Ansible

Hootedit checks what you are editing while you type, in the editor itself: no language server, no subprocess, no extension host. A check runs after a pause in typing (about 2 ms for a 100 KB file, on a thread above 192 KB, skipped above 24 MB), only for the active tab. Problems show as a wavy underline, a coloured bar at the left edge, the message in the status bar when the cursor is on them, and a count at the right (click it, or Ctrl+Shift+M, for the list). F8 and Shift+F8 jump to the next and previous problem, Ctrl+. applies the fix at the cursor, and View > Fix All Problems applies every fix in one undo step. `# noqa` on a line (or `# noqa: code`) silences it. View > Live Checks turns it off.

- **Ansible** (playbooks, `tasks/`, `handlers/`, roles, `group_vars`): the rules of ansible-lint that can be decided from the text: `name[missing]`, `name[casing]`, `name[play]`, `key-order[task]`, `fqcn[action-core]` and `fqcn[action]` (with the full name as the fix), `risky-file-permissions`, `risky-octal` (fix quotes it as "0644"), `no-changed-when`, `command-instead-of-module`, `command-instead-of-shell`, `risky-shell-pipe`, `inline-env-var`, `package-latest`, `no-log-password`, `ignore-errors`, `literal-compare`, `empty-string-compare`, `no-jinja-when` (fix removes the braces), `jinja[spacing]`, `yaml[truthy]`, `no-free-form`, `partial-become`, `deprecated-local-action`, `no-relative-paths`, `no-tabs`, plus a misspelt module or keyword (`shel:` becomes `shell:`), two actions in one task, and duplicate keys. View > Insert Ansible Task (or the palette) offers 28 task skeletons with FQCN names, modes and `changed_when` already in place.
- **Kubernetes** (YAML with `apiVersion` and `kind`, one or many documents; Helm templates with `{{ }}` are left alone): removed or pre-release API versions (`extensions/v1beta1`, `apps/v1beta2`, `batch/v1beta1`, ... with the right one as the fix), a kind with the wrong group, missing `apiVersion`/`kind`/`metadata.name`, names that are not valid DNS names (fix lowercases them), a selector that does not match the pod template labels (the API server rejects those), a missing selector, numbers and booleans where Kubernetes needs strings (`version: 1.2` in labels, `value: true` in env; fix adds the quotes), `containerPort: "80"`, ports out of range, invalid `memory: 1gb` quantities, a bad `imagePullPolicy` or `restartPolicy`, duplicate or unnamed containers, images without a tag or with `:latest`, no `resources` or no memory limit, no readiness probe, privileged containers, `runAsUser: 0`, privilege escalation, `hostNetwork`/`hostPath`, passwords in plain `env` values, and Secrets with their values in the file. View > Insert Kubernetes Resource offers 16 correct skeletons (Deployment with probes, limits and a security context, Service, Ingress, ConfigMap, StatefulSet, CronJob, HPA, NetworkPolicy, RBAC, ...) that pass the checks.
- **Other formats:** TOML (duplicate keys and tables, unterminated strings, `True`/`None`), XML and SVG (mismatched and unclosed tags, unquoted attributes, a bare `&`), Markdown (unclosed code fence, `#Heading` without a space, links to files that do not exist), SQL (`DELETE` or `UPDATE` without `WHERE`, `= NULL`, `SELECT *`), CSS (hex colours with the wrong number of digits), leftover debugging (`dbg!`, `binding.pry`, `var_dump`, empty `catch`), and in every file: invalid UTF-8, mixed line endings and stray lines indented with the other of tabs and spaces. Files that look minified are skipped by the language checks.
- **Other files:** YAML (duplicate keys, tabs), JSON (syntax error with line and column), shell (unquoted variables, `rm -rf $VAR/`, `curl | sh`, `chmod 777`, backticks, `for f in $(ls)`, missing `set -e`, `==` in `sh`), Python (mutable default argument, bare `except`, `== None`, tuple `assert`, mixed tabs and spaces), C and C++ (`gets`, unbounded `strcpy`/`sprintf`, assignment in a condition), JavaScript and TypeScript (`==`, `var`, `debugger`), Dockerfile (untagged or `latest` base image, `apt-get install` without `-y`), Makefile (spaces where a recipe needs a tab), and in every file unbalanced brackets (strings and comments skipped), merge conflict markers, committed secrets (AWS key ids, private keys, GitHub and Slack tokens), trailing whitespace and a missing final newline.
