# Vim keys

Settings > Vim keys (Ctrl+,) switches modal editing on (greyed out when no vim is installed). Normal, insert, visual and visual line modes; counts; operators `d y c > <` with motions and objects (`diw`, `ci"`, `da(`); `x s r J ~ p P u Ctrl+R .`; `:w :q :wq :e file :42` and `/text`, `n` on a command line at the bottom. The engine is built in (`src/vim.cpp`); the installed vim is only checked for.
