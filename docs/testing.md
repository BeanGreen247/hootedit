# Tests

`meson test -C build` runs: the buffer against a plain string model (random edits, ASan and UBSan), the syntax lexer (expected token classes, language detection), undo/redo and save tracking, the regex engine against `std::regex` on 180,000 random cases plus UTF-8 and scan-versus-find checks (ASan and UBSan), and the fuzzy matcher (ranking and extended syntax), the vim engine (operators, objects, registers, macros, surround, dot repeat), the outline scan and the Explorer tree (compact folders, ghost rows, reveal, refresh). `tests/ui_test.sh` is the UI test: it starts the real editor under `xvfb-run` (skipped when there is no display), drives it with `--script` and reads the state back with the `dump` step (tabs, preview flags, text, cursor, status, vim mode, Explorer rows with git status, outline); it covers typing and saving, vim commands including `:%s`, `/` search and `:wq`, preview tabs, compact folders, git markers and ghost rows, the outline toggle, the shortcuts list and quick open. The editor can be driven without a keyboard for screenshots and timing: `hootedit --script "ctrl+n;text:hi;act:search;click:120,150;wait:2000" --shot out.ppm` under `xvfb-run` (steps: key combos, `text:`, `act:NAME`, `menu:N`, `open:PATH`, `mouse:x,y`, `click:x,y`, `wait:MS`, `frame`; add `--timed` to draw a frame per step). The minimum supported window is 1024x768 and is checked.
